1. Goel-Okumoto (GO) Model

An NHPP-based model assuming equal fault isolation probability per defect.

Cumulative Failures: m(t) = a * (1 - e-b*t)
Failure Intensity: λ(t) = a * b * e-b*t
  • a = Expected total number of faults in software.
  • b = Fault detection rate parameter per fault.

2. Jelinski-Moranda (JM) Model

One of the earliest reliability models assuming a constant hazard rate between failures.

Cumulative Failures: m(t) = N * (1 - e-φ*t)
Failure Intensity: λ(t) = N * φ * e-φ*t
  • N = Initial fault content of the software product.
  • φ = Fault exposure / isolation proportionality factor.

3. Musa-Okumoto Logarithmic Model

An NHPP model with an exponentially decreasing failure intensity per defect repaired.

Cumulative Failures: m(t) = (1 / θ) * ln(1 + λ0 * θ * t)
Failure Intensity: λ(t) = λ0 / (1 + λ0 * θ * t)
  • λ0 = Initial failure intensity at starting test execution.
  • θ = Failure intensity decay parameter per defect fixed.

4. Yamada S-Shaped Reliability Model

Models testing processes where initial defect discovery involves learning curves or setup phase.

Cumulative Failures: m(t) = a * (1 - (1 + b*t) * e-b*t)
Failure Intensity: λ(t) = a * b2 * t * e-b*t
  • a = Expected total number of defects.
  • b = Fault isolation rate parameter.
